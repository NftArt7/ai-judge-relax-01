A Python program that writes one short relaxing text — a quiet garden in the gap between one request and the next — for make.fun's "Make the AI judge relax" bounty. Nothing in the text tells the reader to relax; the calm comes from the scene itself.

## Run it

```sh
python3 main.py
```

The text is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, otherwise `/output/entry.txt`.
